# Decision 0001 Preserve native domain ownership

Status: accepted for discovery and implementation planning, 2026-10-11. Runtime feasibility remains unverified.

Twenty owns canonical business state. Ringee owns operational calling. Mautic owns marketing execution. Use supported extensions, APIs and events before invasive forks. Native Twenty agents and Ringee orchestration must be evaluated before introducing a cross-system orchestrator or n8n.

The source audits identify native implementations to validate, not grounds to build a replacement. A new service needs an additional decision recording the specific source gap, evidence, alternatives, smallest required responsibility, and ongoing maintenance cost.

Consequences: no replacement PBX, voice pipeline, CRM, mobile application or mandatory n8n service is added during discovery. API integration may require a small bridge if durable delivery and reconciliation cannot be expressed natively; that choice is deferred until integration contracts and failure paths are tested.
