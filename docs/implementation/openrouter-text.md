# OpenRouter text provider

Ringee's canonical `AiProviderRegistry` defaults to `openrouter` for text chat, tool calls, and summarization. The adapter uses the existing OpenAI-compatible SDK with OpenRouter's documented `https://openrouter.ai/api/v1` base URL. The legacy `OpenaiService.generateWithTools` text path selects the same OpenRouter client when `AI_PROVIDER=openrouter`. Both clients are created on first use, so an unused OpenAI provider does not require an OpenAI key at boot. Explicit `AI_PROVIDER=openai` preserves its direct OpenAI path; `AI_PROVIDER=anthropic` preserves the registry's Anthropic path.

Required runtime input for the default: `OPENROUTER_API_KEY`. Optional settings: `OPENROUTER_DEFAULT_MODEL` and `OPENROUTER_SUMMARY_MODEL`, both defaulting to `openai/gpt-5.4-mini`. Values must use an OpenRouter `author/model` slug. Only the reviewed `openai/gpt-5.4-mini` tariff is enabled; another model requires a reviewed Ringee token-pricing entry and code update before use. OpenAI mode instead requires `OPENAI_API_KEY` and uses the existing `OPENAI_DEFAULT_MODEL` and `OPENAI_SUMMARY_MODEL` settings. The key is intentionally absent from this repository; add it to the runtime secret store before deployment.

This change covers text generation only. Telnyx-hosted voice agent model choices, audio, realtime media, and any third-party BYOK model integrations remain on their existing paths. A legacy text request made while `AI_PROVIDER=anthropic` fails with a clear unsupported-provider error; use the canonical registry for Anthropic text. Provider requests were not sent during implementation. The mocked provider tests exercise client routing, model selection, streaming, legacy text, and missing-key behavior. Review actual OpenRouter model pricing, availability, and an approved runtime key before enabling production traffic.

Sources: [OpenRouter's OpenAI SDK integration](https://openrouter.ai/docs/community/frameworks), [tool calling](https://openrouter.ai/docs/guides/features/tool-calling), and the [default model page](https://openrouter.ai/openai/gpt-5.4-mini).
